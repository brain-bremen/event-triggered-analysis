# Event-Triggered Analysis

[![Build and Test](https://github.com/brain-bremen/event-triggered-analysis/actions/workflows/build-and-test.yml/badge.svg)](https://github.com/brain-bremen/event-triggered-analysis/actions/workflows/build-and-test.yml)
[![Latest release](https://img.shields.io/github/v/release/brain-bremen/event-triggered-analysis)](https://github.com/brain-bremen/event-triggered-analysis/releases/latest)

Plugins for the [Open Ephys GUI](https://github.com/open-ephys/plugin-GUI) that analyse
continuous data in windows locked to an event: a TTL edge, optionally conditioned (setup, commited or cancelled) by a broadcast message.

| Plugin                                                                                                                                                                                                                        | What it does                                                                                    |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------- |
| [**Triggered Average**](https://brain-bremen.github.io/event-triggered-analysis/plugins/triggered-average/) (`Triggered Avg`) ([Docs/plugins/triggered-average.md](Docs/plugins/triggered-average.md))                        | Time-domain average and standard deviation, with individual trials                              |
| [**Receptive Field Bar Mapper**](https://brain-bremen.github.io/event-triggered-analysis/plugins/receptive-field-mapper/) (`RF Barmapper`) ([Docs/plugins/receptive-field-mapper.md](Docs/plugins/receptive-field-mapper.md)) | Visual receptive fields, back-projected from the per-direction trial averages of a sweeping bar |
| [**Triggered Power**](https://brain-bremen.github.io/event-triggered-analysis/plugins/triggered-power/) (`Triggered Power`) ([Docs/plugins/triggered-power.md](Docs/plugins/triggered-power.md))                              | Power spectra accumulated across trials and split by condition                                  |
| [**Triggered Coherence**](https://brain-bremen.github.io/event-triggered-analysis/plugins/triggered-coherence/) (`Triggered Coherence`) ([Docs/plugins/triggered-coherence.md](Docs/plugins/triggered-coherence.md))          | Work-in-progress: Magnitude-squared coherence and coherency phase for configured channel pairs  |
